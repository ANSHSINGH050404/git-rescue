# git-rescue

Git rescue utilities for recovering commits, branches, and lost work.

## Stack

Next.js, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/git-rescue.git
cd git-rescue
npm install
npm run dev   # or: npm start
```
